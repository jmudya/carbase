# Інструкція: як завантажити оновлення з мінімальними витратами кредитів

Мета: 2 публікації в Netlify (по 15 кредитів). Увімкнений "Lock to stop auto publishing" не вимикайте.

## Крок 1. Telegram-бот (до першої публікації)
1. Telegram, @BotFather, команда /newbot. Збережіть токен.
2. Напишіть своєму боту "привіт". Відкрийте https://api.telegram.org/bot<ТОКЕН>/getUpdates і знайдіть "chat":{"id": число}.
3. Netlify, Project configuration, Environment variables: TELEGRAM_BOT_TOKEN і TELEGRAM_CHAT_ID.

## Крок 2. Один коміт на GitHub
1. Розпакуйте carbase-full-update.zip в окрему папку.
2. Репозиторій jmudya/carbase, Add file, Upload files. Перетягніть УСЕ вміст папки (файли і папки admin, data, logos, netlify, vendor).
3. Commit changes один раз.
(Файлів cars.json, settings.json і папки uploads в архіві немає, вони не змінюються.)

## Крок 3. Перша публікація
1. Netlify, Deploys, найновіший деплой, Preview deploy: переглянути безкоштовно.
2. Publish deploy (15 кредитів). Тоді адмінка отримає нові поля, а Telegram почне працювати.

## Крок 4. Наповнення (безкоштовно, поки Lock увімкнений)
1. carbaseusa.com/admin, увійти через GitHub.
2. Contacts and links: Google Analytics ID і посилання на Google-відгуки.
3. Prices and calculators: тарифи на доставку.
4. Видалити зразкові авто, додати свої.
5. Багато фото: червона кнопка внизу праворуч в адмінці (сторінка /admin/photos.html). Там же можна сховати авто.
6. Після кожного змісту натискайте Publish в адмінці (це створює збірку без публікації).

## Крок 5. Друга публікація
Netlify, Deploys, найновіший деплой, Preview deploy, потім Publish deploy (15 кредитів).
