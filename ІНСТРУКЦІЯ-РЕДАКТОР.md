# Редактор прямо на сайті

Відкрийте: carbaseusa.com/?edit=1
(або в старій адмінці натисніть синю кнопку "Редагувати прямо на сайті")

1. Перший раз (і якщо просить): увійдіть в /admin/ через GitHub, потім поверніться на ?edit=1.
2. Натискайте на авто, олівці ✎ біля блоків, або плитку "+ Add car". Зліва меню (☰ Menu).
3. Зміни одразу видно на сторінці, але в GitHub нічого не потрапляє, поки не натиснете "Save changes".
4. "Save changes" зберігає ВСЕ одним комітом. Потім у Netlify опублікуйте найновішу збірку (Publish deploy, 15 кредитів один раз).
5. "Preview" показує сайт очима відвідувача. "Discard" скасовує всі незбережені зміни.

## Тексти сторінки (заголовки, описи, кнопки)
- Кнопка "Aa Texts" внизу: усі тексти на сторінці обводяться пунктиром, натискаєте будь-який і правите в 4 мовах (EN, UA, RU, ES).
- Або меню ☰ -> "Page texts": список усіх текстів за блоками сторінки з пошуком.
- Порожнє поле мови = залишається оригінальний текст. Кнопка "Reset to original" повертає оригінал.
- Зберігаються лише змінені тексти, у файл data/texts.json. Оригінали завжди лишаються в коді.
- Тільки простий текст (символи < і > прибираються). Де в тексті є %s (наприклад "%s reviews"), його треба залишити: замість нього сайт підставляє число.

Старий /admin/ працює як і раніше.
