# Відгуки з Google Maps на сайті

Карусель (3-4 відгуки в ряд зі стрілками) працює одразу з вашими відгуками з редактора.
Щоб до неї автоматично додавались відгуки з Google, потрібні: Place ID, ключ Google і змінна в Netlify.

## Важливо знати
- Google віддає максимум 5 відгуків (найрелевантніші). Решту додавайте вручну в редакторі (Customer reviews): вони йдуть після відгуків Google.
- Google забороняє зберігати ці відгуки, тому сайт питає Google, коли відвідувач докручує до відгуків. Напис "Google Maps", імена авторів і посилання вже додані.
- Це платна послуга Google з безкоштовною квотою. Ліміт GetPlaceRequest у Google змінити НЕ МОЖНА ("Quota is not adjustable"),
  тому захист від зайвих витрат зроблено в самому сайті (див. нижче) + сповіщення про бюджет у Google.

## Кроки
1. Place ID: "Google Place ID Finder", знайдіть "Carbase LLC Tarpon Springs", скопіюйте ID (починається з ChIJ...).
2. console.cloud.google.com: проєкт, Billing (картка), Places API (New) Enable, API key з обмеженням тільки на "Places API (New)".
3. Сповіщення про бюджет: Billing, Budgets & alerts, Create budget (наприклад 10 USD) з листом на пошту.
   Ще можна в Quotas біля потрібного рядка натиснути "Create usage alert".
4. Netlify: Project configuration, Environment variables: GOOGLE_PLACES_API_KEY = ваш ключ (секретне).
   Необов'язково: GOOGLE_DAILY_MAX = 100 (щоденна стеля запитів до Google, за замовчуванням 150).
5. У файлі data/settings.json (або в редакторі, Contacts and links) додайте Place ID у поле gpid. Publish deploy.
6. ПЕРЕВІРКА: відкрийте carbaseusa.com/api/google-reviews. Має бути "ok":true і відгуки. Помилки:
   - GOOGLE_PLACES_API_KEY is not set: ключа немає в Netlify або не було публікації після його додавання;
   - no Place ID in the settings: немає gpid в settings.json або не опубліковано;
   - Google answered 403: не ввімкнено Places API (New), ключ обмежено не тим сервісом або не підключено Billing;
   - Google answered 400/404: неправильний Place ID;
   - daily limit reached: спрацювала денна стеля (нормально, скинеться наступного дня).

## Як сайт захищає вас від витрат
- Netlify обмежує: один відвідувач (IP) може звернутись не більше 6 разів на хвилину.
- Денна стеля запитів до Google (GOOGLE_DAILY_MAX).
- Запит робиться тільки тоді, коли відвідувач докрутив до відгуків, і тільки зі сторінок вашого сайту.
- Старий файл netlify/functions/google-reviews.js замінено заглушкою, яка нічого не робить (його можна видалити).

## Скільки це коштує
За даними сторонніх оглядів станом на середину 2026: запит "Place Details Enterprise + Atmosphere" близько 25 USD за 1000,
перші ~1000 запитів на місяць безкоштовні. Один запит = один відвідувач, що докрутив до відгуків.
Зараз у вас пробний період Google Cloud ($300 на 90 днів). Актуальні ціни: сторінка Google Maps Platform Pricing.

## Вимкнути
Очистіть gpid і опублікуйте. Або видаліть змінну GOOGLE_PLACES_API_KEY у Netlify.
